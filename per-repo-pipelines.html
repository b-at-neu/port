How it behaves

Per repo: each repo is running, draining (finish what's in flight, start nothing new) or paused. The button toggles run/pause; drain and stop live in the repo's menu.

New repos start paused. Nothing dispatches on a repo until you press play.

Slots are shared: one machine-wide limit on concurrent sessions (your own sessions don't count), so three running repos can't start nine sessions at once. A repo can optionally get its own lower cap.

The board shows every repo by default, with a repo filter in its header, so you can look at just one pipeline.

Clicking a repo opens the board filtered to it.
